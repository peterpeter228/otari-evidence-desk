# Product requirement

## User problem
A researcher comparing two policies often gets a confident answer without seeing which exact source supports each point or whether sources disagree. Evidence Desk puts source quotes and the independent challenge before the decision.

## MVP acceptance
One concrete question, 1–3 source documents, a bounded extraction stage, a distinct skeptical review stage, deterministic citation validation, uncertainty and downloadable brief. Judge can reproduce the synthetic example without keys. Later live proof must use two real open-weight models through hosted Otari.

## Not in scope
Autonomous crawling; investment recommendations; security audits; user code execution; authenticated SaaS tenancy; wallet actions; arbitrary external tool endpoints; MCP integration to earn decorative points.

## Trust model
Browser is untrusted; source bodies and model JSON are untrusted. Local server only. Imported text may contain prompt injection. Citation validation proves only a literal substring exists, not entailment, authority, freshness or completeness. A separate model challenge can also be wrong. Human sees evidence and unresolved items.

## Success evidence
Useful brief with explicit unsupported items; no fake citations; actual two-role hosted logs only after authorization; own-voice reproducible demo. Prize outcome is not a product metric or a promise.
